the hardware used for this release from previously documented panel and video
playback results.

| Overlay | `colors=64`, PWM backlight, SPI at 7 MHz |
| Rendering | Ordered dithering (`dither_algo=4`); error diffusion exercised by the smoke test |
| Local framebuffer | `cacheable_buffers=1`; imported DMA-BUF mappings are unchanged |

The `src/` driver sources are unchanged from migration commit `c968425`.
The installer and udev rule changes in this release were also tested on the
device. Source files used for those checks were compared with the release tree.

## Repeatable checks

Software tests and the module/overlay build:

```sh
make -C tests check
make -j4
```

The hardware smoke program requires libdrm development headers. Stop display
producers and save the current display state before running it; it changes
the displayed image and exercises clear and inversion commands.

```sh
cc -O2 -Wall -Wextra $(pkg-config --cflags libdrm) \
  -o /tmp/drm-smoke scripts/drm_smoke.c $(pkg-config --libs libdrm)
echo enable | sudo tee /sys/kernel/debug/sharp_drm/stats
sudo /tmp/drm-smoke /dev/dri/card0 /dev/dri/card1
```

Here `card0` was the Sharp device and `card1` was the VC4 GPU. Identify the
devices on your own system before using these arguments. Restore the saved
image, settings and producer state after testing.

[GitHub Actions](https://github.com/hishizuka/memory-lcd-drm/actions) runs the
unit tests and overlay build on x86 and ARM64, using both GCC and Clang.

## Scope

This release verification used one physical 64-color panel. Other panel sizes,
Sharp monochrome panels and dual-panel configurations have software coverage
and documentation, but were not physically retested during this release run.
Optical image quality was not assessed remotely.

The optional Qt Quick presenter was compiled; a complete Qt application and
the optional ARMv6 FFmpeg build/playback were not rerun here. Previously
documented playback measurements retain their original test conditions.
